## 🌐 Site
👉 [Acesse aqui](https://gomeshs021.github.io/tapiocadamimi/)

---

## 📂 Estrutura
- `index.html` → Página principal da loja  
- `style.css` → Estilos e layout  
- `script.js` → Lógica em JavaScript para carregar produtos  
- `data.json` → Lista de produtos e configurações (WhatsApp)  

---

## ⚙️ Como funciona
- Os produtos são definidos em `data.json`.  
- O site lê os dados e mostra automaticamente na página.  
- Cada produto tem um botão que abre o WhatsApp com mensagem pré-preenchida.  

---

## 🛠️ Personalização
- **Adicionar produtos** → edite `data.json` e faça commit.  
- **Mudar estilo** → edite `style.css`.  
- **Configurar WhatsApp** → altere o número dentro de `data.json`.  

---

## 🔒 Segurança
- Como é uma versão estática, não há login/admin dinâmico.  
- As imagens devem ser adicionadas manualmente ao repositório.
